# Awning releases

Downloads and the update feed for **Awning**, a macOS menu-bar app that warms
and dims your screen and can hold the backlight at 100% to stop PWM flicker.

- **Download:** see [Releases](https://github.com/adamcooper/awning-releases/releases).
- **Website:** https://adamcooper.github.io/awning-releases/
- **Bugs:** [open an issue](https://github.com/adamcooper/awning-releases/issues/new).

The app's source is maintained privately. This repo holds only what users
download: the landing page, the Sparkle update feed (`appcast.xml`) and the
release assets. The files here are published from the source repo by
`scripts/publish_site.sh`; edit them there, not here.
